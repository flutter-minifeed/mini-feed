### 1. 팀 안내에 맞춘 범위 정리

- 프롬프트: 사용자가 제공한 구현 안내대로 #4를 로컬에서 작업하라는 요청.
- AI 응답: main.dart를 MyApp과 FeedScreen 시작 구조로 정리하고, feed_screen.dart·detail_screen.dart·write_screen.dart를 각각 생성. 피드의 임시 버튼 2개와 Navigator.push/MaterialPageRoute로 이동하고, fullscreenDialog로 글쓰기의 기본 X를 사용. 위젯 테스트는 안내의 시작·이동 검사 2개로 교체.
- 판단: 수정. 최신 #4는 빈 화면과 이동 기반만 요구하므로 이전 시험 구현의 카드·아바타·입력창·별도 내비게이션 도우미·디자인 미리보기를 백업 후 제외했다. 상세 화살표와 글쓰기 X는 직접 구현하지 않았다. 실제 기능·데이터는 #7·#8·#9 범위로 남겼다.

### 2. 오프라인 한글 글꼴과 Figma 테마

- 프롬프트: 안내의 Noto Sans KR Regular·Medium·Bold 및 OFL.txt를 넣고 Figma 파운데이션 값으로 테마를 구성하라는 요청.
- AI 응답: 공식 Google Fonts Download all 목록에서 정적 글꼴 3개와 라이선스를 받아 pubspec.yaml에 400·500·700을 등록. Figma 146:2711의 Light 색과 TextTheme를 app_theme.dart 한 곳에 모음.
- 판단: 채택. 안내의 색상 숫자는 예시이므로 실제 Figma 값을 사용했다. google_fonts나 다른 패키지, 자동 다크 전환은 추가하지 않았다. 화면별 색·글자 크기 숫자는 넣지 않았다.

### 직접 검증한 내용·결과

- Flutter 3.47.9 stable / Dart 3.13.7 환경을 유지했다.
- flutter pub get 성공. pubspec.lock과 패키지 의존성은 변경하지 않았다.
- flutter analyze --no-pub: 문제 없음.
- flutter test --no-pub: 총 20개 통과 (#4 위젯 2개, 보존한 #10 시간 계산 18개).
- flutter build web --no-pub 및 flutter build apk --debug --no-pub 성공.
- 정적 TTF의 내부 굵기 400·500·700, 가변 테이블 없음, 웹 FontManifest 등록과 글꼴 파일 3개의 실제 포함을 확인했다.
- #10 함수·테스트·기록 3개는 작업 전후 SHA-256이 동일하다. #10의 실제 기능 화면 연결은 후속 작업으로 남긴다.
- Android 실기기·휴대폰 뒤로가기 버튼·실기기 스크린샷은 미검증이다. SDK 약관 동의도 진행하지 않았다.
