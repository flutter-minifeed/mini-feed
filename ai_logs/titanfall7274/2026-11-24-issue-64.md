### 1. 분석에 사용하는 태그 결정

- 프롬프트: 직접 입력 태그는 본문 분석에 반영하고 추천 선택이 다음 점수를 다시 올리는 반복을 막도록 요청했다.
- AI 응답: 직접 태그를 추가 순서대로 본문 뒤에 붙이고, 저장용 태그와 분석용 문자열을 따로 다룬다.
- 판단: 채택. 같은 이름도 사용자가 입력했는지 추천을 선택했는지에 따라 분석에 포함할지가 다르다.

### 직접 검증한 내용·결과

- Python에서 앱 모델로 계산한 결과와 짧은 태그의 한계를 [입력 규칙과 기술 보고서 변경분](../../docs/topic-analysis-input.md)에 기록했다.
- 화면 검사에서 추천 선택과 중복 입력은 추가 요청을 만들지 않았고, 제거 후 같은 이름을 직접 확정했을 때 분석 입력이 바뀌었다. 본문이 빈 상태에서 직접 태그를 바꾸고 키보드를 닫자 새 요청이 발생했고, 이전 요청이 늦게 실패해도 새 후보가 유지됐다.
- Galaxy S23 Ultra(SM-S918N)에 `557005a`를 설치했다. 기기 모델은 Python 기준 7건의 특징 벡터·8개 점수·추천을 재현했다. 점수의 절대 오차 허용값은 0.00001이다.
