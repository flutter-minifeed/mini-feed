### 4. 해제 뒤 텐서 읽기 오류

- 판단: 수정. 테스트만 고치면 #27·#28에서 같은 실수가 반복되어 클래스 쪽에서 막음

### 5. API 24 검증

- 프롬프트: API 24를 다른 테스트 사이트에서 확인할 수 있는지 질문
- AI 응답: `minifeed-285b2`의 Firebase Test Lab 기기 212개 중 API 24 지원 기기가 없음(최저 가상 26·실기기 27)을 확인. 로컬 에뮬레이터는 실기기 검증이 아니어서 이슈 기준상 결과가 바뀌지 않는다며 처음에는 미완료로 두기를 권함
- 판단: 수정. 기기를 구할 수 없어 API 24 에뮬레이터로 실행했고, `libtensorflowlite_jni.so` 로드가 `cannot locate symbol "strtod_l"`로 실패. 세 ABI 모두 `strtod_l@LIBC_O`(API 26부터 제공)를 요구해 API 24·25에서는 모델을 쓸 수 없음을 확인. minSdk 26 상향, 26 미만에서 추천 끄기, Dart 직접 계산을 비교해 minSdk를 26으로 올림. 24는 #3에서 Flutter 기본값을 쓴 값이라 유지할 근거가 없었음

### 6. 앱 크기

- 프롬프트: 추론 라이브러리로 APK가 커지는 문제 검토 요청
- AI 응답: `tflite_flutter`가 GPU 라이브러리(`litert-gpu`)를 항상 함께 넣지만 Dense 한 층 모델이라 GPU 위임이 필요 없고, GPU 라이브러리는 `GpuDelegateV2`를 만들 때만 열림을 확인. `packaging.jniLibs.excludes`로 제외를 제안. TFLite 없이 Dart로 직접 계산하는 방법은 기술 보고서 방향을 바꾸는 결정이라 이번 범위에서 뺌
- 판단: 채택. 기기당 약 2.5MB, APK의 GPU 라이브러리 3개(6.69MB) 제외
