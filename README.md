## 실행 절차

Flutter 3.47.9 stable / Dart 3.13.7, Android 최소 API 24

Android 패키지 ID: `com.minifeed`

1. `flutter doctor`로 환경 확인
2. 저장소 루트에서 `cd app` 실행 후 `flutter pub get`
3. `flutter run`
