# MP1 완료 기준

과제 페이지의 MP1 기준을 옮겨 적은 문서예요. 기준이 바뀌면 과제 페이지를 따르고 이 문서도 함께 고쳐요.

## 단계 목표

SNS 앱의 얼굴인 피드를 만드는 단계예요. 더미 데이터로 게시글 목록(닉네임·작성 시각·내용), 글쓰기 화면, 게시글 상세 화면을 구현해요. 서버는 아직 없어요. 스크롤이 자연스러운 피드 UI와 작성 흐름에 집중하고, MP2의 서버 동기화는 이 화면 위에 올라가요.

## MVP

더미 게시글 10개가 스크롤 피드로 표시되고, 새 글을 작성하면 피드 최상단에 나타나며, 게시글을 탭하면 상세 화면으로 이동하는 상태

## 학습 목표

- 게시글 카드(닉네임·작성 시각·내용)로 구성된 스크롤 피드 구현
- 글쓰기 화면에서 작성한 글을 피드 최상단에 추가
- 게시글 탭 시 상세 화면으로 이동
- 작성 시각을 '5분 전' 같은 상대 시간으로 표시

## 평가 기준

다음 3가지를 모두 충족하면 통과예요.

1. 피드·글쓰기·상세 세 화면과 화면 간 이동이 동작한다.
2. 새 글이 피드 최상단에 추가되고 상대 시간이 표시된다.
3. 더미 데이터에 실명·연락처 등 실제 개인정보가 없다.

## 제출

완성한 소스코드를 ZIP으로 압축해 제출해요. 실제 키가 든 `.env`와 `build/` 같은 설치·빌드 폴더는 넣지 않아요.

ZIP을 열었을 때 아래 항목이 바로 보여야 해요. 필수 항목이 빠지면 평가가 진행되지 않을 수 있어요. 이 문서가 있는 `docs/`는 제출 항목이 아니라서 ZIP에서 빼요.

| 항목 | 필수 | 내용 |
| --- | --- | --- |
| `app/` | 필수 | 피드 앱 소스 전체 |
| `README.md` | 필수 | 화면 구성, 더미 데이터 구조, 실행 절차 |
| `screenshots/` | 필수 | 피드·글쓰기·상세 화면 각 1장 이상 |
| `prompts_log.md` | 필수 | 바이브 코딩에 사용한 주요 프롬프트와 AI 응답의 채택/수정 내역 |

```
제출.zip
├── app/
├── README.md
├── screenshots/
└── prompts_log.md
```
