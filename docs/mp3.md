# MP3 완료 기준

과제 페이지의 MP3(3단계 — 상호작용과 안전장치) 기준을 옮겨 적은 문서예요. 기준이 바뀌면 과제 페이지를 따르고 이 문서도 함께 고쳐요.

## 단계 목표

SNS를 SNS답게 만드는 마지막 단계예요. 좋아요와 댓글을 추가해 사용자 간 상호작용을 완성하고, 동시에 SNS가 반드시 갖춰야 할 안전장치 — 게시글 신고 기능과 커뮤니티 가이드라인 — 를 만들어요. 기능과 책임을 한 세트로 경험하는 것이 이 단계의 핵심이에요.

선행 조건은 MP2 통과예요. 같은 앱에 이어서 작업해요.

## MVP

좋아요 토글과 댓글 작성이 두 기기 간 동기화되고, 게시글을 신고하면 사유와 함께 서버에 기록되는 상태

## 학습 목표

- 게시글 좋아요(토글, 중복 방지)와 댓글 작성·목록을 구현하기
- 게시글 신고 기능(사유 선택→서버 기록)을 구현하기
- 금지 콘텐츠와 신고 처리 원칙을 담은 커뮤니티 가이드라인 문서 작성하기
- 상호작용 데이터(누가 좋아요했는지)의 노출 범위를 결정하고 이유를 기록하기

## 평가 기준

다음 3가지를 모두 충족하면 통과예요.

1. 좋아요(중복 방지 포함)와 댓글이 동작하고 기기 간 동기화된다.
2. 신고 기능이 사유와 함께 서버에 기록된다.
3. GUIDELINES.md에 금지 콘텐츠·신고 처리 원칙·상호작용 데이터 노출 범위가 기술되어 있다.

## 제출

완성한 소스코드를 ZIP으로 압축해 제출해요. 실제 키가 든 `.env`와 `build/` 같은 설치·빌드 폴더는 넣지 않아요.

ZIP을 열었을 때 아래 항목이 바로 보여야 해요. 필수 항목이 빠지면 평가가 진행되지 않을 수 있어요. 이 문서가 있는 `docs/`는 제출 항목이 아니라서 ZIP에서 빼요.

| 항목 | 필수 | 내용 |
| --- | --- | --- |
| `app/` | 필수 | 좋아요·댓글·신고가 추가된 최종 앱 소스 |
| `README.md` | 필수 | 전체 기능 목록, 상호작용 데이터 구조, 실행 절차 |
| `GUIDELINES.md` | 필수 | 커뮤니티 가이드라인 — 금지 콘텐츠, 신고 처리 원칙, 상호작용 데이터 노출 범위와 이유 |
| `screenshots/` | 필수 | 좋아요·댓글 동기화(두 기기), 신고 흐름, 서버의 신고 기록 각 1장 이상 |
| `prompts_log.md` | 필수 | 바이브 코딩에 사용한 주요 프롬프트와 AI 응답의 채택/수정 내역 |

```
제출.zip
├── app/
├── README.md
├── GUIDELINES.md
├── screenshots/
└── prompts_log.md
```
