# MP2 완료 기준

과제 페이지의 MP2(2단계 — 서버와 동기화하기) 기준을 옮겨 적은 문서예요. 기준이 바뀌면 과제 페이지를 따르고 이 문서도 함께 고쳐요.

## 단계 목표

내 폰 안의 피드를 모두의 피드로 만드는 단계예요. Firebase 또는 Supabase를 연동해 게시글을 서버에 저장하고, 다른 기기(에뮬레이터 2개)에서 같은 피드가 보이는 것을 확인해요. 사용자 식별은 익명 인증만 사용하고, 당겨서 새로고침으로 최신 글을 불러와요.

선행 조건은 MP1 통과예요. 같은 앱에 이어서 작업해요.

## MVP

기기 A에서 작성한 글이 서버에 저장되고, 기기 B에서 새로고침하면 그 글이 보이는 상태

## 학습 목표

- BaaS(Firebase/Supabase)에 게시글을 저장하고 목록을 불러오기
- 익명 인증으로 기기별 사용자 식별을 구현하기 (이메일·전화번호 수집 금지)
- 두 개의 에뮬레이터·기기에서 같은 피드가 보이는 것을 확인하기
- 당겨서 새로고침과 작성 실패(네트워크 오류) 안내를 처리하기

## 평가 기준

다음 3가지를 모두 충족하면 통과예요.

1. 두 기기 간 게시글 동기화가 스크린샷으로 확인된다.
2. 익명 인증만 사용하며 이메일·전화번호 등 개인정보 수집 코드가 없다.
3. 설정 키가 분리되어 있고 작성 실패 안내가 처리되어 있다.

## 제출

완성한 소스코드를 ZIP으로 압축해 제출해요. 실제 키가 든 `.env`와 `build/` 같은 설치·빌드 폴더는 넣지 않아요.

ZIP을 열었을 때 아래 항목이 바로 보여야 해요. 필수 항목이 빠지면 평가가 진행되지 않을 수 있어요. 이 문서가 있는 `docs/`는 제출 항목이 아니라서 ZIP에서 빼요.

| 항목 | 필수 | 내용 |
| --- | --- | --- |
| `app/` | 필수 | 서버 동기화가 추가된 앱 소스 |
| `README.md` | 필수 | 선택한 BaaS와 이유, 익명 인증 방식, 백엔드 설정 절차, 실행 절차 |
| `.env.example` | 필수 | 필요한 설정 키 목록 (실제 값 제외) |
| `screenshots/` | 필수 | 기기 A 작성 화면 + 기기 B 동기화 화면 + 백엔드 콘솔 데이터 각 1장 이상 |
| `prompts_log.md` | 필수 | 바이브 코딩에 사용한 주요 프롬프트와 AI 응답의 채택/수정 내역 |

```
제출.zip
├── app/
├── README.md
├── .env.example
├── screenshots/
└── prompts_log.md
```
