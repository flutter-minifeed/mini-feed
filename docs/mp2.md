# MP2 완료 기준

과제 페이지의 MP2(2단계 — 서버와 동기화하기) 기준을 옮겨 적은 문서예요. 기준이 바뀌면 과제 페이지를 따르고 이 문서도 함께 고쳐요.

2026-11-17 운영 측 개정 공지에 따라 평가 기준과 제출 규칙을 고쳤어요. 아래 평가 기준은 공지의 변경표를 옮긴 것이라, 과제 화면의 문구가 다르면 과제 화면을 따라요. README 작성 규칙(실행 절차·확인 방법), Flutter 버전, 잠금 파일, 스크린샷 규칙 같은 공통 규칙은 [MP1 완료 기준](mp1.md)의 제출 절을 따라요.

## 단계 목표

내 폰 안의 피드를 모두의 피드로 만드는 단계예요. Firebase 또는 Supabase를 연동해 게시글을 서버에 저장하고, 다른 기기(에뮬레이터 2개)에서 같은 피드가 보이는 것을 확인해요. 사용자 식별은 익명 인증만 사용하고, 당겨서 새로고침으로 최신 글을 불러와요.

선행 조건은 MP1 통과예요. 같은 앱에 이어서 작업해요.

## MVP

기기 A에서 작성한 글이 서버에 저장되고, 기기 B에서 새로고침하면 그 글이 보이는 상태

## 학습 목표

- BaaS(Firebase/Supabase)에 게시글을 저장하고 목록을 불러오기
- 익명 인증으로 기기별 사용자 식별을 구현하기 (이메일·전화번호 수집 금지)
- 두 개의 에뮬레이터·기기에서 같은 피드가 보이는 것을 확인하기
- 당겨서 새로고침과 작성 실패(네트워크 오류) 안내를 처리하기

## 평가 기준

다음 5가지를 모두 충족하면 통과예요.

1. 기기 A에서 작성한 글이 기기 B에서 새로고침한 뒤 표시된다.
2. 익명 인증만 사용하며 이메일·전화번호 등 개인정보 수집 코드가 없다.
3. 작성 실패 시 크래시 없이 안내한다.
4. 설정 키를 하드코딩하지 않고, `.env.example`만 제출한다.
5. README에 BaaS 선택·익명 인증·백엔드 설정·확인 방법·실행 절차 절이 있다.

## 제출

완성한 소스코드를 ZIP으로 압축해 제출해요. 실제 키가 든 `.env`와 `build/`·`.gradle/`·`.dart_tool/` 같은 빌드 산출물은 넣지 않아요.

ZIP을 열었을 때 아래 항목이 바로 보여야 해요. 필수 항목이 빠지면 평가가 진행되지 않을 수 있어요. 이 문서가 있는 `docs/`는 제출 항목이 아니라서 ZIP에서 빼요.

| 항목 | 필수 | 내용 |
| --- | --- | --- |
| `app/` | 필수 | 서버 동기화가 추가된 앱 소스 |
| `README.md` | 필수 | 선택한 BaaS와 이유, 익명 인증 방식, 백엔드 설정 절차, 실행 절차, 확인 방법 |
| `.env.example` | 필수 | 필요한 설정 키 목록 (실제 값 제외) |
| `screenshots/` | 필수 | 기기 A 작성 화면 + 기기 B 동기화 화면 + 백엔드 콘솔 데이터 각 1장 이상. `01_` 번호, 최대 12장, 한 장 2MB 이하 |
| `prompts_log.md` | 선택 | AI 사용에 쓴 주요 프롬프트와 AI 응답의 채택/수정 내역. 우리 팀은 내지 않고 `ai_logs/`에만 남겨요. |

```
제출.zip
├── app/
├── README.md
├── .env.example
├── screenshots/
└── prompts_log.md
```
