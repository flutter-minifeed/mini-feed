# 게시글 삭제와 하위 기록

앱은 트랜잭션에서 게시글을 읽고, 글 삭제와 `deletedPosts/{postId}` 기록 생성을 함께 요청한다. 서버 규칙은 기존 글의 작성자만 이 두 변경을 함께 저장하도록 허용한다. 삭제 기록에는 서버 시각만 남긴다. 글 ID는 게시 재시도에도 사용하므로, 삭제 기록이 있는 ID는 다시 쓸 수 없다.

Firestore에서 글을 삭제해도 하위 컬렉션은 남는다. 댓글 읽기는 상위 글이 있을 때만 허용하며, 현재 좋아요·신고 원본에는 앱 접근 권한이 없다. 이후 상호작용 쓰기 규칙을 열 때도 커밋 직후 상위 글이 존재하는지 확인해야 한다.

앱에는 다른 사용자의 하위 기록을 일괄 삭제할 권한을 주지 않는다. 운영자가 잔여 데이터를 정리할 때는 삭제 기록의 ID로 상위 글이 없는지 확인하고 해당 글의 하위 컬렉션을 재귀 삭제한다. 일부만 정리된 경우 같은 ID로 이어서 정리할 수 있다. 정리 후에도 ID 재사용 방지를 위해 삭제 기록은 보관한다.
