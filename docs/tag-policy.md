# 게시할 태그 개수 정책

입력·게시 기준은 [명세서 AI3·AI4·R14](https://app.notion.com/p/3db8d812628a80b1b0bdc22a8396c60c)를 따른다.

[기술 보고서 2.3·3장](https://app.notion.com/p/4068d812628a8074a861e5f0f965dd96)에 반영할 변경문은 다음과 같다.

> 추천 후보는 최대 3개다. 사용자가 고른 태그는 개수 상한 없이 게시글의 `tags` 문자열 배열에 추가 순서대로 저장한다. 앱과 Firestore 생성 규칙은 각 이름의 길이·허용 문자와 영문 대소문자를 무시한 중복을 검사한다. 태그가 없는 기존 글도 조회할 수 있다. 게시글이 Firestore의 문서 크기 한도를 넘어 저장에 실패하면 본문과 태그를 유지해 수정 후 다시 게시할 수 있다.
